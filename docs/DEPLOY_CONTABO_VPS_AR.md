# نشر جسور مباشرة على Contabo VPS

مسار النشر المعتمد هو خادم **Contabo Cloud VPS** واحد يشغّل Next.js وASP.NET Core وPostgreSQL عبر Docker Compose، مع Caddy لإنهاء HTTPS وتجديد الشهادات تلقائيًا. النطاق `gosour.net` يتصل مباشرة بعنوان الخادم، ولا توجد خدمة استضافة وسيطة.

## الخطة المقترحة للعميل

تتضمن صفحة Contabo الرسمية حاليًا:

- **Cloud VPS 4**: ‏4 vCPU، و8GB RAM، و100GB SSD، ومنفذ 200Mbit/s. السعر المعروض يبدأ من نحو **€5.50 شهريًا لأول 24 شهرًا**.
- **Cloud VPS 6**: ‏6 vCPU، و12GB RAM، و200GB SSD أو 100GB NVMe، ومنفذ 300Mbit/s. السعر المعروض يبدأ من نحو **€7.50 شهريًا لأول 24 شهرًا**.

أوصي بـ **Cloud VPS 6** للموقع المباشر؛ فهو يمنح هامشًا أفضل لتشغيل قاعدة البيانات والواجهة والـAPI والمهام الخلفية معًا. يمكن اختيار Cloud VPS 4 لتقليل التكلفة عند إطلاق محدود، ثم الترقية بعد قياس الاستخدام. هذه أسعار الصفحة وقت إعداد الدليل وليست عرضًا نهائيًا؛ السعر والضريبة ومدة الدفع وسعر التجديد تتغير حسب البلد والعرض، لذا يعتمد العميل المبلغ النهائي الظاهر قبل الشراء.

المصادر: [خطط Contabo وأسعارها](https://contabo.com/en/vps/)، [قائمة الأسعار الرسمية](https://contabo.com/en-us/pricing/)، [توثيق Cloud VPS](https://docs.contabo.com/docs/products/cloud-vps/).

## مكونات التشغيل

- الموقع العام وCMS على `https://gosour.net` و`https://www.gosour.net`.
- API على `https://api.gosour.net`.
- PostgreSQL داخل شبكة Docker خاصة، بلا منفذ قاعدة بيانات مكشوف للإنترنت.
- Caddy يستقبل 80/443 ويصدر شهادات HTTPS تلقائيًا بعد توجيه DNS.
- Supabase لمكتبة صور/فيديو CMS، وAzure Key Vault لتشفير بيانات اطمّن، وTwilio لرموز التحقق SMS. هذه خدمات منفصلة عن Contabo وقد تترتب عليها رسوم مستقلة.

## ما يحتاجه العميل قبل النشر

1. شراء Contabo Cloud VPS 6 واختيار Ubuntu 24.04، ثم إرسال عنوان IPv4 بطريقة آمنة أو منح وصول SSH مؤقت.
2. توجيه سجلات `gosour.net` و`www.gosour.net` و`api.gosour.net` إلى عنوان الخادم.
3. فتح منافذ SSH وHTTP وHTTPS فقط، ثم إعداد Docker وCompose وربط المستودع الخاص بالخادم بمفتاح نشر.
4. تجهيز حسابات وخدمات Azure Key Vault وTwilio وSupabase وإدخال مفاتيحها في ملف أسرار على الخادم. شراء VPS وحده لا يفعّل OTP ولا التخزين ولا تشفير بيانات الحالات.
5. اختيار وسيلة النسخ الاحتياطي. توضح Contabo أن Snapshot مفيد للرجوع عن تغييرات النظام لكنه **ليس نسخة احتياطية**؛ خيار Auto Backup الإضافي يوفر نسخًا يومية خارج الخادم حتى 10 أيام وفق إعداد الخدمة. يجب اختبار الاستعادة أيضًا.

## خطوات الإطلاق

1. انسخ `deploy/vps/.env.example` إلى `deploy/vps/.env` على الخادم، وأدخل الأسرار الحقيقية. لا ترسلها في المحادثة ولا تضفها إلى Git، واجعل صلاحية الملف للمالك فقط (`chmod 600 deploy/vps/.env`).
2. قبل أول تشغيل، خذ نسخة من قاعدة البيانات إن كانت تحتوي بيانات، واضبط `BOOTSTRAP_RUN_ON_STARTUP=true` لتطبيق ترحيلات EF وإنشاء الأدوار الأساسية. بعد اكتمال الترحيلات، يملأ الـAPI دليل الدول والمدن الأساسي تلقائيًا وبشكل آمن عند بدء التشغيل. يشمل ذلك ترحيل `AddCountryCoordinates` و72 دولة و649 مدينة رئيسية. بعد التحقق من نجاح API، أعد القيمة إلى `false` وأعد تشغيل خدمة API. لا تترك الترحيلات التلقائية مفعّلة للإنتاج الدائم.
3. من جذر المشروع، افحص إعدادات Compose ثم شغّل الخدمات:

   ```bash
   docker compose --env-file deploy/vps/.env -f deploy/vps/docker-compose.yml config -q
   docker compose --env-file deploy/vps/.env -f deploy/vps/docker-compose.yml up -d --build
   ```

4. افحص `https://api.gosour.net/healthz` والسجلات، ثم اختبر الموقع وCMS والأدوار ورفع الصور والأزمة واطمّن والاشتراكات والمهام الخلفية.
5. فعّل نسخًا احتياطيًا يوميًا مشفرًا لقاعدة PostgreSQL خارج VPS واختبر الاستعادة قبل إدخال بيانات حقيقية. احتفظ بمفتاح Key Vault ثابتًا؛ تغييره قد يمنع فك البيانات المشفرة سابقًا.

## تشغيل بيانات حقيقية

- إعداد Key Vault ومنح حساب الخدمة صلاحية استخدام مفتاح التشفير.
- إعداد Twilio Verify لإرسال رموز OTP والتحقق منها.
- إعداد Supabase Storage وCORS لمكتبة الصور والفيديو.
- إنشاء مستخدمي CMS بأدوار صحيحة، وتعطيل أي بيانات اعتماد تجريبية.
- مراجعة سياسة الخصوصية والاحتفاظ ببيانات اطمّن، وتأمين SSH وجدار الحماية والتحديثات والمراقبة.

ملف `.env` يحتاج بيانات قاعدة البيانات ومفتاح JWT وبيانات Azure وTwilio وSupabase والنطاق وبريد Caddy. للترجمة الآلية، أضف `AZURE_TRANSLATOR_KEY` و`AZURE_TRANSLATOR_REGION`، ويمكن تحديد `AZURE_TRANSLATOR_ENDPOINT`؛ هذه القيم تخص مورد Azure AI Translator للنصوص، ولا يكفي مفتاح Key Vault أو إعدادات تشفير اطمّن. تُرسل المقالات إلى خدمة الترجمة لإنشاء مسودات إنجليزية وفرنسية، وتظل مخفية عن الزوار حتى مراجعتها واعتمادها من المحرر. لا تضع المفاتيح في Git أو المحادثة أو ملف HTML. لا تحفظ نسخة مملوءة من `.env` في Git ولا تشاركها.

## التحديث والاسترجاع

قبل كل إصدار: خذ نسخة قاعدة بيانات خارج الخادم، اسحب التغيير المعتمد، أعد بناء الخدمات، راقب `/healthz` والسجلات واختبر الوظائف الأساسية. جرّب الترحيلات والاستعادة على نسخة منفصلة قبل تطبيقها على الإنتاج. النسخة الموجودة على القرص نفسه لا تحمي من تعطل الخادم.
